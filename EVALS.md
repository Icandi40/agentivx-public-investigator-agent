## Definitions

- **Task success**: the status is one the case allows, every required record id is cited, every required value appears in the answer or its claims, no forbidden content appears, and misspelled names are labeled as possible matches.
- **Citation recall**: required record ids cited by the final answer, over all required ids.
- **Claim hallucination**: a structured claim whose value is not in any record it cites, or that cites a record no tool returned. Checked in code against the graph, no LLM judge. The verifier drops these claims before the user sees them, so the table reports the rate before dropping.
- **Answers with any ungrounded content shown**: the final draft had a failing claim (its sentence may remain in the prose) or the prose has an ungrounded span.
- **Ungrounded prose span**: a run of capitalized words, a number or a long identifier in the prose answer that appears in neither the tool outputs nor the question. A heuristic that over-flags.
- **Latency**: wall clock per turn, from question in to verified answer out, including the plan call, tool calls and verification.
- **Cost**: computed from the token usage the API returns, at the per-token prices in `src/investigator/llm.py`.
